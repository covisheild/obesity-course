# Terms of art, and the plain words they get at first use

Add rows; never change one mid-book. A new row goes in its alphabetical place. `claude.md` §10 requires that a term is introduced once and afterwards used in the
same words. The build enforces that inside a booklet; this file is what enforces it across
booklets, which matters as soon as more than one chat is writing. See `PARALLEL.md`.

**Before teaching a term of art, look for it here.** If it is listed, teach it in the plain words
recorded here. If it is not, add the row in the same commit that first teaches it.

Changing an existing row means every booklet that used it must change too. That is a
between-rounds job, never something a chat does mid-book.

Rebuilt at the Book 0 freeze, 23 September 2026, from the records of all six Parts (`B0-R0-C01` to
`B0-R0-C43`). One table, alphabetical, one row per term. The plain words are the record's own,
shortened. Where one term has two senses, the row names both, numbered, each with the record that
teaches it, and the last column lists those records in reading order. Rows for terms no record now
teaches were deleted. Terms used before their gloss, and terms used for two things, are listed in
`books/B0/GLOSSARY-MERGE-REPORT.md` §5 for a later record pass.
