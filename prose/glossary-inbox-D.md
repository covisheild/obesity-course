# Glossary inbox · D

New terms taught in `B0-R0-C24` to `B0-R0-C30` (Part D, D1 to D7: chance, variation, average and
spread, sampling, measurement error). Held here rather than written into `GLOSSARY.md` because the
Part D, E and F chats were adding rows at the same time, and `PARALLEL.md` routes concurrent
additions through an inbox for the human to merge. Taken from the records as they stand, in reading
order (definition, then "In plain terms", then illustration); the plain words are the record's own,
trimmed only to the gloss. Every term has one plain-words gloss at its first use (ruling M20); where
a formula, symbol or standards quote sits beside it, the row keeps that too.

| Term | Plain words it gets at first use | First taught in |
| --- | --- | --- |
| probability | a number from 0 to 1 that states how often an outcome would turn up if the same chance process were repeated a great many times | B0-R0-C24 |
| relative frequency | the fraction of all the tries in which it happened | B0-R0-C24 |
| sample space | the complete list of everything that could happen | B0-R0-C24 |
| outcome | one member of that list [the sample space] | B0-R0-C24 |
| event | any collection of outcomes from it [the sample space] | B0-R0-C24 |
| complement | every outcome in the sample space that is not in it | B0-R0-C24 |
| odds | how many times more likely the event is than its opposite: p divided by (1 minus p) | B0-R0-C24 |
| at random | every rural person has exactly the same chance of being the one you pick | B0-R0-C24 |
| independent | the knowledge that one has happened tells you nothing about the chance of the other | B0-R0-C25 |
| mutually exclusive | they cannot both happen | B0-R0-C25 |
| two-way table (also contingency table) | sorts one group of people by two categories at once, one down the rows and one across the columns | B0-R0-C26 |
| cell | the count where a row meets a column | B0-R0-C26 |
| grand total | adding every cell | B0-R0-C26 |
| conditional probability | restricts which total a count is divided by | B0-R0-C26 |
| sensitivity | the share of people with the condition that the test catches, written P(test positive given condition present) | B0-R0-C26 |
| specificity | the share of people without the condition that the test correctly clears, written P(test negative given condition absent) | B0-R0-C26 |
| positive predictive value | the share of positive results that are right, written P(condition present given test positive) | B0-R0-C26 |
| prevalence | how many people in a group have the condition, written P(condition present) | B0-R0-C26 |
| negative predictive value | the share of negative results that are right | B0-R0-C26 |
| distribution | the set of values a quantity takes, across the people, occasions or measurements counted, together with how often each value turns up | B0-R0-C27 |
| frequency table | lists each value, or each band of values, against the count of times it occurred | B0-R0-C27 |
| range | its largest value minus its smallest | B0-R0-C27 |
| shape | where its values sit relative to each other | B0-R0-C27 |
| long tail | thin out slowly on one side and quickly on the other | B0-R0-C27 |
| mean (also average) | their sum divided by how many there are | B0-R0-C28 |
| median | the middle value of the same set once it is ordered from smallest to largest | B0-R0-C28 |
| quartile | one of three values that divide an ordered set into four equal-sized parts | B0-R0-C28 |
| interquartile range | the third quartile minus the first | B0-R0-C28 |
| population | the whole group a question is about | B0-R0-C28 |
| sample | the part of that group that was actually measured | B0-R0-C28 |
| deviation | that value minus the mean | B0-R0-C28 |
| variance | worked out from the squared deviations: add them, then divide by the count for a whole population, or by one less than the count for a sample | B0-R0-C28 |
| standard deviation | the square root of the variance, expressed in the same unit as the original values | B0-R0-C28 |
| parameter | a number that describes the population, if every member of it could be measured | B0-R0-C29 |
| statistic | the same kind of number, computed instead from a sample | B0-R0-C29 |
| estimate | a number made from part of the group and used to stand in for the whole | B0-R0-C29 |
| random sample | picked at random: every member of the population has exactly the same chance of being the one picked, and an actual chance process decides it, not the person picking | B0-R0-C29 |
| convenience sample | built out of whoever happens to be available | B0-R0-C29 |
| sampling bias | some members of the population are more likely to be chosen than others, so the sample leans towards them | B0-R0-C29 |
| sampling variation | draw a second random sample of the same size from the same population and its statistic will not match the first sample's exactly | B0-R0-C29 |
| square-root law | this spread equals the spread of the individual values in the population, divided by the square root of the sample size | B0-R0-C29 |
| standard error of the mean | this spread [of a random sample's average over many samples of the same size] | B0-R0-C29 |
| self-selected sample | they chose to come forward | B0-R0-C29 |
| nonsampling error | error [that] has nothing to do with how a sample was drawn | B0-R0-C30 |
| error (measurement error) | the value it returns minus the value that is actually true, or, since the true value is usually unknown, minus a trusted reference value it is checked against | B0-R0-C30 |
| systematic error | pushes every reading the same way, by close to the same amount, every time | B0-R0-C30 |
| measurement bias | an error that points one way and does not shrink when you collect more (VIM 2.18: an "estimate of a systematic measurement error") | B0-R0-C30 |
| random error | pushes readings both above and below the true value | B0-R0-C30 |
| measurand | the quantity being measured | B0-R0-C30 |
| accuracy | how close a measured value comes to the true value | B0-R0-C30 |
| trueness | how close the average of many repeated readings sits to the true value | B0-R0-C30 |
| true on average | when this closeness [trueness] is good | B0-R0-C30 |
| precision (measurement sense) | how closely repeated readings agree with each other | B0-R0-C30 |
| resolution | the "smallest change in a quantity being measured that causes a perceptible change in the corresponding indication"; for a digital display, in practice the step of its last digit | B0-R0-C30 |
| zero error | an instrument reading something other than zero when it should read zero | B0-R0-C30 |
| correction | subtract it [a systematic error of known size] from every reading | B0-R0-C30 |
| calibration | measuring a machine against something already known, so its readings mean something | B0-R0-C30 |
| calibration weight | a weight already checked and trusted to be correct | B0-R0-C30 |

*Rulings (DECISIONS-part-D-fix.md).* M5: C28 gives population and sample in the ruled words,
and C29 reuses them unchanged. M8: C24 glosses relative frequency as ruled, and C27 reuses it. M9:
sampling bias is taught in C29 and measurement bias in C30, which calls it the same word for the
same shape of problem. M10: C30 quotes the glossary's loose precision words verbatim, then narrows
to the VIM sense; resolution is named apart. All four are followed.

*Rows already in GLOSSARY.md.* **calibration**: C30 uses the registered words exactly, but the
row says first taught in `B0-R0-C32`; it must move to `B0-R0-C30`. **precision**: C30 uses the
registered words; the row's `B0-R0-C39` is already known to be wrong (first use `B0-R0-C03`), and D
adds a narrower VIM sense, so the merged row wants both senses, as with denominator.
**proportion**: C24 and C27 reuse the registered words. No wording conflicts.

*F2 inbox note.* D does not teach "spread", "uncertainty" or "error bar" as terms. "Spread" is used
informally from C27 and pinned only in C29 ("its own spread, meaning its standard
deviation"); "uncertainty" occurs once in C29, in its ordinary sense and unglossed; "error bar" never occurs. F2's
**whisker** row stands as written.

seven terms glossed twice in different words (odds, population/sample, estimate, convenience sample,
