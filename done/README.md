# This folder no longer holds the records

They live in `check/records/B0/` — that is the only copy, and it is the one `check/build.py`
reads. Until 20 Sep 2026 this folder held a second, hand-copied set. It was byte-identical the
day it was made and had no mechanism keeping it that way: an edit to one copy produced zero
build feedback, because the build has never read this directory. The count had already gone
stale once — every reference to "the four finished sections" was still saying four after
Part A brought the total to twelve — which is what a copy nobody re-derives does over time.

`B0-as-published.docx` stays. It is a rendered snapshot, not a source, and there is nothing for
it to drift out of sync with.

Read `check/records/B0/` for the standard. Match it.
