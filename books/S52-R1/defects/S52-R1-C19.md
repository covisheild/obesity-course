7. **style** (rendering) · `practice[6].prompt`: "The file has a BMI column, `BMXBMI`, in kg/m^2, beside
   weight `BMXWT`"
   - This is the build's "empty-looking span" (`_build/S52-R1.md` line 10169; the HTML shows a literal
     caret). The cause is in `build.py` `_notation`: the inline-code pattern
     `` `[^`\n]*[\^~][^`\n]*` `` matches from the closing backtick of `BMXBMI` to the opening backtick of
     `BMXWT`. It parks ", in kg/m^2, beside weight " as verbatim code, so the caret is never typeset.
   - Record fix: put the unit where no backtick comes before it on the line: "The file has a BMI column in
     kg/m^2, named `BMXBMI`. Beside it are weight `BMXWT` ...".
   - Tool (conductor): the pattern should match only real code spans, by pairing backticks from the
     start of the line.
   - Recurring (SELFCHECK 19).
