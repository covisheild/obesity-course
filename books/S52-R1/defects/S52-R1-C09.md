`S52-R1-C07.md`.

word for word. The files are `r4ds_2e.txt`, `broman_woo_2018_tas.txt`, `wilson_2017.txt`,
`rdocs_s52r1_readr.txt`, `rdocs_s52r1_readxl.txt`, `rdocs_s52r1_haven.txt` and
`nchs_nhanes_2021_2023_bmx_demo.txt`. Each number quote states its number: "Missing 106 8860",
361, 389 and 670 are BMX_L codebook table rows. No quote field changed. Two prose claims have no
quote behind them: item 6.

**Code and arithmetic.** The code gate ran 12 sessions with 0 failures. Recomputed in Python with
pandas, reading the `.xpt` files directly:

- BMX_L is 8860 × 22 and DEMO_L is 11933 × 27;
- missing values: BMXWT 106, BMXHT 361, BMXBMI 389, BMXWAIST 670;
- weight or height is missing in 389 rows, the same rows as BMI;
- 8754 rows have a weight (8860 − 106 = 8754), mean 70.54904 kg, minimum 2.7 kg;
- the penguin file's MD5 is `049da101568e078f9845c8b366481810`, as in the README;
- 11 penguins have no sex.

DEMO_L has 3073 people "Interviewed only", which supports P6's "not everyone screened was
examined". The set climbs, levels 1 to 10.

**Figures.** `nhanes-missing`: 106, 361, 389 and 670, from the table block. `camp-minus-99`: 128,
−99 and 131 drawn from a zero line, minimum −99. Both agree with the prose. The NHANES caption says
"not survey estimates", and Illustration 3 and P9 say the summary is unweighted, as the brief requires.

without `I()`. This record already uses `I()` throughout, so nothing breaks. The parse warning's
wording (`dat <- vroom(...)`) is version-specific; see item 5. NHANES 2021–2023 is stamped

revision.
