**Quotes.** All 22 definition quotes and 21 number quotes (`peng_2011`, `trisovic_2022`) are in their files.
Each number's quote states the number. **One quote edited:** `definition.references[20]`, cited for "Most
packages came from the social sciences". It quoted why R and Stata are popular on Dataverse, which does not

**The study against the held text.** Trisovic et al., Sci Data 2022, is an observational re-execution study,
not an experiment. It took 2109 Harvard Dataverse packages (2010 to July 2020) holding 9078 detected R files.
Each file ran in a clean Docker environment under R 3.2, 3.6 and 4.0, with 1 hour per file and 5 per package,
in two runs, without and with automatic cleaning. A file was a success if any version succeeded, and TLE files
were excluded. The record states the design, the sample, the time limits and the two bases (abstract against
table) correctly, apart from items 1, 4 and 6. Peng 2011 is a perspective piece; its Fig. 1 is an image (item 2).

**Arithmetic.** Recomputed in Python: 952+2878+3829 = 7659; 1472+2223+3719 = 7414; 1581+1238+5790 = 8609;

1581/8609 = 0.1836. The table totals match. No practice set (`quantitative: false`). **Figures:** both specs
match the table and the derived shares, and the bars start at zero. **Amendments:** none named; O3 and G are
served.

**Currency.** The data run to July 2020, under R versions up to 4.0. The review trigger, 2028-10-02, is
reasonable. Before the next review, look for a newer large re-execution study; none is held.
