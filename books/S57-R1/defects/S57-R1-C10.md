3. **`must_know[5]`, the CBME levels** (from compression hole H6, corrected)
   - **Claim:** "Its tables give each skill a level: K (knows), KH (knows how), SH (shows how) or P
     (performs). A skill at SH cannot be tested on paper: the learner must show you."
   - **What the source says:** the levels table describes K as "A knowledge attribute - Usually
     enumerates or describes" and KH as "A higher level of knowledge - is able to discuss or
     analyze". So K and KH are not skill levels: "each skill" is wrong, and should be "each
     competency". The table does not say how any level is assessed. "Cannot be tested on paper" is
     the book's inference from SH's "demonstrate a complex procedure", which is fair but is not the
     curriculum's words. H6 asked for "one line each from the CBME Curriculum 2024 on how K, KH and P
     are assessed". No held passage gives that. What the curriculum does give is a "Suggested
     Assessment method" column for each competency, and P's row: "When done independently under
     supervision a pre-specified number of times - certification".
   - **Smallest fix:** "Its tables give each competency a level: K (knows: enumerates or describes),
     KH (knows how: discusses or analyses), SH (shows how: demonstrates) or P (performs, certified
     after a set number of supervised performances). Each row also names a suggested assessment
     method. Read both before you write the test. A competency at SH or P has to be watched." Add a
     reference quoting the P row. Writing the pairs as "knows how (KH)" also clears the build's
     acronym list, which reports KH and SH as unexpanded.
   - **Tag:** error (K and KH called skills). **Recurring** (SELFCHECK 1: the claim goes beyond the
     quote).
   - Fixer: checked the source (levels table p. 31, P row: "When done independently under supervision a pre-specified number of times - certification"). must_know[5] now says "competency", glosses each level in the table's words, names the suggested assessment method, and ends "A competency at SH or P has to be watched"; the P-row reference quote extended to the certification words.
